# OBJ Viewer
A simple program to view `.obj` models!
## Controls
* **Left Click + Drag**: Rotate / orbit camera
* **Mouse Scroll Wheel**: Zoom in / out
* **Spacebar**: Toggle auto-rotation on/off
* **Escape**: Exit
## System Requirements
* **OS**: Windows 10 64-bit or newer
* **GPU**: OpenGL 4.6 Core Profile support
* **Display**: 1024 × 768 minimum resolution
## Dependencies
* Microsoft Visual C++ 2015–2022 Redistributable (x64)
